# Olist E-Commerce Data Science Project

This project is a weekly data science journey using the Olist Brazilian E-Commerce dataset. The aim is to apply the concepts learned in my B.Tech CSE (Data Science) course to a real-world dataset.

The project will gradually progress from understanding and cleaning the raw data to exploratory data analysis, descriptive and diagnostic analytics and many more.

## Dataset

The dataset contains information about:
- Customers
- Orders
- Order Items
- Payments
- Reviews
- Products
- Sellers
- Geolocation
- Product Categories


## Objective

The main objective is to understand how raw real-world data can be transformed into meaningful insights and eventually used to support predictions and data-driven decisions.

## Dataset Source

The Olist Brazilian E-Commerce Public Dataset is used for educational and academic purposes. Dataset attribution is given to Olist and the original dataset source.
